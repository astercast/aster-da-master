## Structure

- `index.html` — the whole site (hero, latest transmission, discography, listen, about, connect, eras, numbers, codex, deep cuts, on this day, cast lots, milestones, first & last, milestone watch)
- `releases/` — one static page per release + filterable index, generated by `scripts/build_releases.py`
- `sessions.html` — 61 upload sessions clustered from vault dates (`scripts/build_sessions.py`); `sessions/` — deep-dive pages for the top-10 sessions (`scripts/build_session_deepdives.py`)
- `glance.html` — the 60-second infographic: every headline number, top tracks, eras, sessions, collaborators (`scripts/build_glance.py`)
- `changelog.html` — site construction history from `git log` (`scripts/build_changelog.py`)
- `press-kit.html` — one-page press kit rendered from the API data, with `@media print` styling
- `timeline.html` — interactive career timeline (2018–2026), rendered client-side by `assets/js/timeline.js`
- `network.html` — collaboration network graph, rendered client-side by `assets/js/network.js`
- `decoder.html` — codex-powered word search across all 219 titles (`assets/js/decoder.js`)
- `api-playground.html` — interactive explorer for the 12 `data/v1/` endpoints (`assets/js/playground.js`)
- `assets/css/` — `tokens.css`, `base.css`, `layout.css`, `components.css` (modular, no frameworks)
- `assets/js/site.js` — renders discography/platforms/socials/bio from `data/artist.json`; reveal-on-scroll
- `assets/js/common.js` — shared helpers (`esc`, `parseCollabs`, `loadData`, era-span parsing) for standalone pages
- `data/artist.json` — the single source of truth (populated by research, v0.11.0)
- `data/v1/release-slugs.json` — discography index → release-page slug (for search deep-links; built by `scripts/build_search_index.py`)
- `data/v1/on-this-day.json` — "MM-DD" → tracks on that month-day across years (powers the homepage "On this day" section)
- `data/codex.json` — vocabulary codex, computed by `scripts/build_codex.py`
- `data/v1/` — machine-readable artist record + schema (`API.md`)
- `skills/` — agent task procedures (announce-release, verify-platform-links, build-press-kit)

## Aesthetic rules

- Minimal: one idea per screen, vast negative space
- Signal: phosphor green is the voice, amber is the heat; mono labels everywhere — restraint, not overload
- Texture: faint scanlines + vignette, corner-tick marks on cards, manifest-style track rows
- Reduced motion respected everywhere; semantic HTML; keyboard navigable
