# Cover archive: provenance

Durable in-repo copies of the 35 release covers this site serves from Apple
Music's CDN (the cover ladder's second rung, data/art.json). Copied by the
Asset Foundry, Round 851, 2026-10-24, at 1000x1000 from the same CDN base
each page already uses, so a dead CDN address can never lose the art.
Pages are unchanged: they still serve the ladder (own file in assets/art/
first, then Apple by address, credited on the page). This folder is the
archive of record only and is excluded from the deploy tree in
.vercelignore. Provenance per cover: source Apple Music (mzstatic CDN),
album page and collection id from data/art.json (scripts/art_apple.py,
verified live against both artist profiles on the copy date: 35 of 35
still listed, artwork bases unchanged, zero further Apple art exists for
the remaining 186 releases).
